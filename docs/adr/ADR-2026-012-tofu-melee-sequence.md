# ADR-2026-012: Tofu data-defined melee sequence adapter
Date:2026-10-18. Status:Implementation mapping of user-authorized sixth hero.

Existing core interfaces, class schema, damage ordering, save format and Augment policy are unchanged. A Bruiser role uses existing brute class. New generic MeleeComboBasic and MeleeSequenceExecutor/MeleeSequenceRuntime compose existing CombatService hit/resolver, bounded contexts/Echo, radius modifiers, statuses, invulnerability, and the same collision-aware move_and_collide primitive used by TimedCombatEffect. The new runtime is justified by per-tick multi-hit dedup, delayed chain steps, capped retargets, final-hit-only procs and independently expiring debris, which the existing one-hit-per-dash executor does not express. J/L share one implementation; no duplicated per-character projectile/damage core.

Basic combo step belongs to Actor metadata; immutable Resources hold only config. Movement uses the existing optional weak runtime lock added for Doom. Fear is a local bounded EnemyActor steering component, restoring previous processing ownership, never applying to bosses. Visual adapter binds through optional SpriteFrames metadata; global VFX factory unchanged. Existing five kits untouched. Rejected changing class enum, native input, viewport or source command engine.

Source side-view coverage is labelled2_DIR_POC_ONLY. Semantically unverified SND voices are not assigned; original nonvoice fallback implements audible action feedback while source audio remains available in an offline catalog. Archive checksum unavailable. Tests must verify real melee/fields/walls, echo scales and lifetime, fear restoration, Augment rejection, exact roster20/7/13, existing heroes, PLAY/TRAINING and cleanup. User approves images/listening separately.
